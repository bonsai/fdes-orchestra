# Skill

Skillは、Awareに対して実行できる能力である。

```text
Aware → Skill → Action
```

例:

```text
waiting
  → detect_friction
  → observe / record / classify

information_gap
  → identify_missing_information
  → compare / question / symbolize

deviation
  → compare_expected_actual
  → compare / classify / update_model
```

Skillを目的化しない。MissionとAwareから必要なSkillだけを選ぶ。
